# Toto’s Toolkit downloads

Toto’s Toolkit is an unofficial Pokémon Champions companion with a fast type weakness lookup, damage calculator, team builder, and Speed tiers. Its four themes are Dark, Light, Pokédex, and Totodile.

This repository is for public download documentation and Android test release attachments. Application source is maintained separately.

## Android testing

The first planned prerelease is **0.1.5, build 6**. When available in this repository’s Releases page, download `totos-toolkit-0.1.5-test.apk` and follow the attached `ANDROID_TESTING.md`. Use `SHA256SUMS.txt` to verify downloads. GitHub’s automatic ZIP/TAR archives contain the repository documentation; the APK is the installable app.

Back up teams before updating a test build. This APK uses a generated test signing key. Store releases and iPhone distribution remain in preparation.

## Included release files

- Android test APK
- Installation and test instructions
